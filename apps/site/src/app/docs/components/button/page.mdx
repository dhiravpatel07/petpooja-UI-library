# Button

The primary action trigger. One component covers every documented Pantheon variant — four visual styles, two shapes, four sizes, optional leading/trailing icons, and a square icon-only mode.

Pressed maps to the native `:active` state; disabled uses the standard gray palette and blocks pointer events. Pixel-perfect port of Figma node `36:1881` (Pantheon › Buttons).

## Installation

<InstallCommand name="button" />

Or via npm:

```bash
pnpm add @petpooja/ui
```

## Usage

```tsx
import { Button } from '@petpooja/ui';

export function Demo() {
  return <Button>Save changes</Button>;
}
```

## Variants

Four visual treatments cover almost every action UI: solid **Primary** for the page's main action, tinted **Tonal** for a softer brand emphasis, neutral **Outline** for secondary actions, and ghost **Text** for low-emphasis or inline use.

## Icon placement

Pass any React node to `leadingIcon` / `trailingIcon`. Inline SVGs are auto-sized per `size` (18 / 18 / 20 / 24 px), so you don't need to size them yourself.

<ComponentPreview
  previewClassName="!min-h-[140px] !p-8"
  preview={<ButtonIconPlacement />}
  code={`<Button>Label</Button>
<Button leadingIcon={<PlayIcon />}>Label</Button>
<Button trailingIcon={<ArrowRightIcon />}>Label</Button>
<Button shape="round" leadingIcon={<PlayIcon />} trailingIcon={<ArrowRightIcon />}>
  Label
</Button>`}
/>

## States

The Pressed state is rendered while a pointer or key is active on the button — there's no separate prop. Disabled is the standard `disabled` attribute.

<ComponentPreview
  previewClassName="!min-h-[260px] !p-8"

<Button variant="outline" disabled>Outline</Button>

## Icon-only

Set `iconOnly` to render a perfect square (32 / 36 / 40 / 48 px) with the icon centered and no minimum width. Pair it with `aria-label` for screen readers since there's no text content.

<ComponentPreview
  previewClassName="!min-h-[220px] !p-8"
  preview={<ButtonIconOnly />}
  code={`<Button iconOnly aria-label="Add">
  <PlusIcon />
</Button>

<Button shape="round" iconOnly aria-label="Add">
  <PlusIcon />
</Button>`}
/>
