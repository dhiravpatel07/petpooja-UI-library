# Tabs

Horizontal navigation between panels of related content. Selected tab gets a 1.5px brand underline; hover gets a soft `#fafafa` background.

Built on **Radix Tabs** so ARIA roles (`role="tablist"`, `role="tab"`, `role="tabpanel"`), focus management, and arrow-key navigation come for free. Pixel-perfect port of Figma node `47:626`.

The Figma documents four sizes (`xs / sm / md / lg`) and three compositions (text + icon / text only / icon only) — all handled by **one component**. Size is a prop on `TabsList` that cascades to every trigger; composition is whatever you pass as children.

## Installation

<InstallCommand name="tabs" />

