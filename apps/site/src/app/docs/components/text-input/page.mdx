# Text Input

Notched-outline text field with a floating label. One component covers every Pantheon variant — three sizes, five states, prefix / suffix slots, leading + trailing icons, an inline primary CTA, and supporting helper / error text.

Pixel-perfect port of Figma node `66:685` (Pantheon › Text Input). The "notch" is rendered without a `<fieldset>`/`<legend>` so you can hand a real `<input>` to consumers — the cutout effect comes from a `bg-white` slice on the floated label that overlays the border line.

## Installation

<InstallCommand name="text-input" />

Or via npm:

```bash
pnpm add @petpooja/ui
```

## Usage

```tsx
import { TextInput } from '@petpooja/ui';

export function Demo() {
  const [email, setEmail] = useState('');
  return (
    <TextInput
      label="Email"
      type="email"
      value={email}
      onChange={(e) => setEmail(e.target.value)}
      helperText="We'll send a verification link."
    />
  );
}
```

## States

Five states cover the full Figma spec. Default is empty + unfocused; Active is what focus looks like; Input is "has value, not focused"; Error toggles the red treatment plus an inline message; Disabled paints the `#F5F5F5` wash.

## Leading + trailing icons

Pass any 18 / 20 px SVG into `leadingIcon` / `trailingIcon`. Add `onTrailingIconClick` to make the trailing slot a clear button (or a password reveal, a refresh, etc.).

<ComponentPreview
  previewClassName="!p-8"
  preview={<TextInputIconsDemo />}
  code={`<TextInput
  label="Email"
  value={value}
  onChange={(e) => setValue(e.target.value)}
  leadingIcon={<MailIcon />}
  trailingIcon={<CloseIcon />}
  onTrailingIconClick={() => setValue('')}
  helperText="We'll send a verification link."
/>`}
/>

## Prefix slot

The prefix slot is a left-attached chunk separated from the input by a 1 px divider — perfect for country codes, currency selectors, or any dropdown trigger.

## Inline CTA

`cta` renders an attached primary button on the right edge — fuses to the field's outer border, takes the Pantheon `buttons/primary` treatment. Disable it independently of the input via `ctaDisabled`.

<ComponentPreview
  previewClassName="!p-8"
  preview={<TextInputCtaDemo />}
  code={`<TextInput
  label="Promo code"
  value={code}
  onChange={(e) => setCode(e.target.value)}
  cta="Apply"
  ctaDisabled={code.trim().length === 0}
  onCtaClick={() => apply(code)}
  helperText="Enter a promo code to see the discount."
/>`}
/>

## Password reveal

`onTrailingIconClick` makes the trailing slot interactive — swap the icon between open and closed eye states and toggle the input `type`.

<ComponentPreview
  previewClassName="!p-8"
  preview={<TextInputPasswordDemo />}
  code={`const [show, setShow] = useState(false);
return (
  <TextInput
    label="Password"
    type={show ? 'text' : 'password'}
    value={value}
    onChange={(e) => setValue(e.target.value)}
    trailingIcon={<EyeIcon open={show} />}
    onTrailingIconClick={() => setShow((s) => !s)}
    helperText="At least 8 characters."
  />
);`}
/>

## Search — no label

Skip `label` to use the field as a plain placeholder-only input. The trailing-icon clear pattern works without a label too.

### `TextInputIcon`

20 × 20 inline-flex helper for callers that need to drop a consistent icon into a `prefix` or `suffix` slot. Inherits `text-black` so any SVG using `currentColor` picks up the right fill.
