# Bottom Sheet

A mobile-style modal anchored to the bottom of the viewport. Slides up over an overlay; dismisses via the close icon, ESC key, or clicking outside.

Built on **Radix Dialog** primitives — focus trap, ARIA roles, scroll lock, and keyboard handling come for free. Composable header / title-group / footer slots match the Figma component (node `66:687`) pixel-for-pixel and let consumers compose any of the three documented states.

## Installation

<InstallCommand name="bottom-sheet" />

Or via npm:

```bash
pnpm add @petpooja/ui
```

## Anatomy

```tsx
<BottomSheet>
  <BottomSheetTrigger />
  <BottomSheetContent>
    <BottomSheetHeader>
      <BottomSheetTitleGroup>
        <BottomSheetTitle />
        <BottomSheetDescription />
      </BottomSheetTitleGroup>
      <BottomSheetCloseIcon />
    </BottomSheetHeader>

    {/* arbitrary body content */}

    <BottomSheetFooter>
      <BottomSheetClose />
      {/* primary action */}
    </BottomSheetFooter>
  </BottomSheetContent>
</BottomSheet>
```

## States

Three documented states from Figma. Each is just a different composition of the same primitives — no separate variants required.
