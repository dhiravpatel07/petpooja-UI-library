# Color

The full Pantheon color system as drop-in React primitives. Ten palettes — Primary, Secondary, four Accents, Gray, and three status families — wrapped in three composable parts: `ColorSwatch` for a single shade, `ColorPalette` for a column, and `ColorSystem` for the whole page.

Every shade in the registry is the verbatim hex from Figma. Foreground labels auto-contrast against the background using WCAG relative luminance, so light and dark shades both stay readable without manual overrides. Pixel-perfect port of Figma node `66:689` (Pantheon › Colors).

## Installation

<InstallCommand name="color" />

Or via npm:

```bash
pnpm add @petpooja/ui
```

## Usage

```tsx
import { ColorSystem, COLOR_PALETTES } from '@petpooja/ui';

export function Demo() {
  return <ColorSystem palettes={COLOR_PALETTES} />;
}
```

Or render a single shade anywhere:

```tsx
import { ColorSwatch } from '@petpooja/ui';

<ColorSwatch label="Primary 500" hex="#1770EE" />;
```

## Single swatch

`ColorSwatch` is the atomic unit — pass any hex, get a 80&nbsp;px row with the label on the left and the uppercase hex on the right. Foreground flips to white once the background drops below ~50% luminance.

The Gray ramp goes from `Gray 0` (pure white) through `Gray 1000` (pure black) — 11 stops total. The pure-white swatch keeps a faint ring so its bounds remain visible against light surfaces.

## API

### `ColorSwatch`

Extends every standard `<div>` attribute. The background and foreground are applied inline via `style` so any hex works — Tailwind never sees the value.

### Data exports

Every palette is exported as both a named constant and as a member of the canonical `COLOR_PALETTES` array, so you can use the data directly in your own components (token tables, Storybook stories, theme builders, etc.).

```ts
import {
  COLOR_PALETTES,
  PRIMARY_PALETTE,
  SECONDARY_PALETTE,
  YELLOW_PALETTE,
  AQUA_PALETTE,
  GREEN_PALETTE,
  BEIGE_PALETTE,
  GRAY_PALETTE,
  ERROR_PALETTE,
  WARNING_PALETTE,
  SUCCESS_PALETTE,
  readableTextColor,
} from '@petpooja/ui';
```

`readableTextColor(hex)` returns `"#000000"` or `"#ffffff"` — the same helper `ColorSwatch` uses internally for its label color.
