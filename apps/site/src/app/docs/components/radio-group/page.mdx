# Radio Group

A single-select group of radio buttons. Use when the user must pick exactly one option from a small list.

Built on **Radix RadioGroup** so ARIA roles, focus management, arrow-key navigation between items, and form integration come for free. Pixel-perfect port of Figma node `2381:1299`.

## Installation

<InstallCommand name="radio-group" />

Or via npm:

```bash
pnpm add @petpooja/ui
```

## Usage

```tsx
import { RadioGroup, RadioGroupItem } from '@petpooja/ui';

export function Demo() {
  return (
    <RadioGroup defaultValue="email">
      <label className="flex items-center gap-3">
        <RadioGroupItem value="email" id="email" />
        <span>Email</span>
      </label>
      <label className="flex items-center gap-3">
        <RadioGroupItem value="sms" id="sms" />
        <span>SMS</span>
      </label>
    </RadioGroup>
  );
}
```
