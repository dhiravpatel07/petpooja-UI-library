# Side Drawer

Edge-anchored modal that slides in from the right (or left) of the viewport and fills the full height. Three documented Figma states map to composition rather than props:

- **Default** — header + scrolling body with sections + CTA footer
- **Zero State** — header + centered media + centered title/description + CTA footer
- **Custom** — header + an arbitrary body slot (no built-in spacing)

Built on **Radix Dialog** so focus trap, ESC dismissal, click-outside, scroll lock, and ARIA roles come for free. Pixel-perfect port of Figma node `2400:18` (Pantheon › Side Drawer).

## Installation

## Anatomy

```tsx
<SideDrawer>
  <SideDrawerTrigger />
  <SideDrawerContent side="right">
    <SideDrawerHeader>
      <SideDrawerTitleGroup>
        <SideDrawerLeadingIcon />
        <SideDrawerTitleStack>
          <SideDrawerTitle />
          <SideDrawerSubtitle />
        </SideDrawerTitleStack>
      </SideDrawerTitleGroup>
      <SideDrawerCloseIcon />
    </SideDrawerHeader>

    <SideDrawerBody divided>
      <SideDrawerSection>
        <SideDrawerSectionTitle />
        <SideDrawerText />
      </SideDrawerSection>
      <SideDrawerSeparator />
      {/* …more sections */}
    </SideDrawerBody>

    <SideDrawerFooter>
      <SideDrawerCancelButton />
      <SideDrawerConfirmButton />
    </SideDrawerFooter>
  </SideDrawerContent>
</SideDrawer>
```

## API

### `SideDrawer`

Root. Re-export of `Radix Dialog.Root`. Accepts every standard Dialog prop.

<PropsTable
  rows={[

    { name: 'onOpenChange', type: '(open: boolean) => void', description: 'Fires whenever the drawer opens or closes.' },
    { name: 'modal', type: 'boolean', default: 'true', description: 'When true (the default) traps focus and blocks outside interactions.' },
  ]}
/>

### `SideDrawerContent`

The 550&nbsp;px panel. Renders into a portal, anchored to the chosen viewport edge.

<PropsTable
  rows={[
    {
      name: 'side',
      type: '"right" | "left"',

    },
    {
      name: 'hideOverlay',

    },
  ]}
/>

### `SideDrawerHeader` · `SideDrawerTitleGroup` · `SideDrawerTitleStack` · `SideDrawerTitle` · `SideDrawerSubtitle` · `SideDrawerLeadingIcon` · `SideDrawerCloseIcon`

Header subparts. `SideDrawerLeadingIcon` defaults to the Pantheon back-arrow; pass children to override. `SideDrawerCloseIcon` is the 40×40 outline button in the top-right that auto-dismisses the drawer via `Radix Dialog.Close`.

### `SideDrawerBody`

The flex-1, scrolling body. Add `divided` to apply a 24&nbsp;px gap between top-level children (typically `<SideDrawerSection>` blocks).

### `SideDrawerSection` · `SideDrawerSectionTitle` · `SideDrawerText` · `SideDrawerSeparator`

Optional section helpers. `<SideDrawerSection>` applies 24&nbsp;px horizontal padding and a 16&nbsp;px vertical gap between children; `<SideDrawerSeparator>` is the full-width `#D9D9D9` hairline; the text helpers apply the Pantheon Body Large + Body Medium type tokens.

### `SideDrawerFooter` · `SideDrawerCancelButton` · `SideDrawerConfirmButton`

Footer + preset buttons. The footer reserves a 1&nbsp;px top border, 16&nbsp;px padding, and a 16&nbsp;px gap; buttons are 48&nbsp;px tall, 12&nbsp;px radius, `flex-1` with `max-w-200` so they don't overstretch on wide drawers. Wrap the cancel button in `<SideDrawerClose asChild>` to auto-dismiss on click.

### `SideDrawerActionCta`

Small 32&nbsp;px outline chip used inside section headers (e.g. an "Edit" affordance next to a content title). 8&nbsp;px radius, Title Small typography.

### `SideDrawerMedia` · `SideDrawerZeroState` · `SideDrawerZeroStateTitle` · `SideDrawerZeroStateDescription`

Zero-state helpers. `SideDrawerMedia` is a 250&nbsp;px tall `#F0F0F0` placeholder block (override the height with the `height` prop); `SideDrawerZeroState` is the centered media + text wrapper.

## Keyboard

| Key            | Behavior                                       |
| -------------- | ---------------------------------------------- |
| <kbd>Esc</kbd> | Close the drawer and return focus to the trigger. |
| <kbd>Tab</kbd> | Cycle focus inside the panel (focus trap).     |
