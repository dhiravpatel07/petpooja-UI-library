# Badge

A small status indicator. Two sizes:

- **Large** — a coloured pill containing a short label (e.g. "New").
- **Small** — an 8×8 dot.

Pixel-perfect port of Figma node `50:155` from the Pantheon design file.

## Installation

<InstallCommand name="badge" />

Or via npm:

```bash
pnpm add @petpooja/ui
```

## Usage

```tsx
import { Badge } from '@petpooja/ui';

export function Demo() {
  return (
    <div className="flex items-center gap-3">
      <Badge size="small" />
      <Badge size="large">New</Badge>
    </div>
  );
}
```

## API

<PropsTable
  rows={[
    {
      name: 'size',
      type: "'large' | 'small'",
      default: "'large'",
      description: (
        <>
          Visual variant. <code>large</code> shows children as text inside a coloured pill.{' '}
          <code>small</code> renders an 8×8 dot — children are ignored.
        </>
      ),
    },
    {
      name: 'className',
      type: 'string',
      description: (
        <>
          Additional classes, merged with the base styles via <code>tailwind-merge</code>.
        </>
      ),
    },
    {
      name: 'children',
      type: 'ReactNode',
      description: <>Label text shown in the Large variant. Ignored when <code>size="small"</code>.</>,
    },
  ]}
/>

The component also accepts every standard `<span>` prop (forwarded to the underlying element).
