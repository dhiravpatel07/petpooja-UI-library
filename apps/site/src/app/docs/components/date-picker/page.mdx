# Date Picker

Full date-range picker UX from Figma node `3980:641` — a bottom-sheet panel with a header, range display, calendar grid, quick-pick chips (Today / Yesterday / Last 7 days / etc.), and Cancel / Confirm actions.

Built on **`react-day-picker`** for the calendar engine (date math, month nav, keyboard navigation, locale handling, accessible semantics) and `date-fns` for preset calculations. Pixel-perfect to the Figma design — `34×34` cells, `8px` corner radius, `#3a84ec` selected fill, `#ebf3fd` range strip, all matched exactly.

The full Figma UX — try clicking dates to build a range, or tap a preset chip. The committed range is shown after you Confirm.

## Using inside a Bottom Sheet

DatePicker is presentational — drop it into your existing modal/sheet. With our BottomSheet:

```tsx
'use client';
import { useState } from 'react';
import {
  BottomSheet,
  BottomSheetTrigger,
  BottomSheetContent,
  DatePicker,
} from '@petpooja/ui';

export function Demo() {
  const [open, setOpen] = useState(false);
  return (
    <BottomSheet open={open} onOpenChange={setOpen}>
      <BottomSheetTrigger>Pick a date</BottomSheetTrigger>
      <BottomSheetContent className="!h-auto !max-w-[375px]">
        <DatePicker
          onChange={(range) => {
            console.log(range);
            setOpen(false);
          }}
          onCancel={() => setOpen(false)}
        />
      </BottomSheetContent>
    </BottomSheet>
  );
}
```
