# Chip

Compact selectable label for filters, tags, and quick-pick choices. One component covers every documented Pantheon variant — four sizes, two shapes, three states, and any combination of leading / trailing icons.

Pressed maps to the native `:active` state; Selected is a controlled `selected` prop you toggle from your own state. Pixel-perfect port of Figma node `57:165` (Pantheon › Chips).

## Installation

<InstallCommand name="chip" />

Or via npm:

```bash
pnpm add @petpooja/ui
```

## Usage

```tsx
import { useState } from 'react';
import { Chip } from '@petpooja/ui';

export function Demo() {
  const [selected, setSelected] = useState(false);
  return (
    <Chip selected={selected} onClick={() => setSelected((v) => !v)}>
      Bestseller
    </Chip>
  );
}
```

## States

Active is the idle state. Pressed appears while the pointer is held (no prop required). Selected is a controlled flag that switches to the brand-tinted treatment.

## Single-select filter

A common pattern: bind `selected` to a single piece of state to build a filter bar.

<ComponentPreview
  previewClassName="!min-h-[120px] !p-8"
  preview={<ChipFilterDemo />}
  code={`const FILTERS = ['All', 'Veg', 'Non-veg', 'Spicy', 'Bestseller'] as const;

export function FilterBar() {
  const [active, setActive] = useState<(typeof FILTERS)[number]>('All');
  return (
    <div className="flex flex-wrap gap-2">
      {FILTERS.map((filter) => (
        <Chip
          key={filter}
          size="sm"
          selected={active === filter}
          onClick={() => setActive(filter)}
        >
          {filter}
        </Chip>
      ))}
    </div>
  );
}`}
/>
