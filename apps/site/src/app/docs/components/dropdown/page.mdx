# Dropdown

Composable menu surface for selection, filtering, and multi-pick flows. Four documented combinations from Figma — **Search × CTA** — built out of three reusable item families (default, checkbox, and CTA buttons).

Built on **Radix Popover** so anchored positioning, ESC dismissal, click-outside, and focus return come for free. Pixel-perfect port of Figma node `2768:141` (Pantheon › Dropdown).

## Installation

<InstallCommand name="dropdown" />

Or via npm:

```bash
pnpm add @petpooja/ui
```

## Anatomy

```tsx
<Dropdown>
  <DropdownTrigger />
  <DropdownContent>
    <DropdownSearch />               {/* optional */}
    <DropdownList>
      <DropdownItem />
      <DropdownCheckboxItem />
      <DropdownSeparator />
    </DropdownList>
    <DropdownFooter>                 {/* optional */}
      <DropdownCancelButton />
      <DropdownConfirmButton />
    </DropdownFooter>
  </DropdownContent>
</Dropdown>
```

### `DropdownTrigger`

Re-export of `Popover.Trigger`. Use `asChild` to attach the open/close behavior to any element you provide.

### `DropdownContent`

The 250&nbsp;px panel. Renders into a portal, anchored to the trigger. Adds the Pantheon shadow + 10&nbsp;px radius automatically.

### `DropdownFooter` · `DropdownCancelButton` · `DropdownConfirmButton`

Preset CTA row. The footer reserves a fixed 56&nbsp;px height; both buttons are 36&nbsp;px tall and share the row equally (`flex-1`). Cancel = `Buttons/Tertiary` outline, Confirm = `Buttons/Primary` fill — both render as native `<button type="button">` elements so they accept every standard prop including `onClick`, `disabled`, `aria-*`.

### `DropdownList` · `DropdownSeparator` · `DropdownLabel`

Optional grouping helpers. `DropdownList` is a `role="menu"` flex column with 4&nbsp;px vertical padding; `DropdownSeparator` is the `E5E5E5` hairline; `DropdownLabel` is the small uppercase group header in `#666666`.

## Keyboard

| Key                | Behavior                                                        |
| ------------------ | --------------------------------------------------------------- |
| <kbd>Tab</kbd>     | Standard tab order (search → items → footer).                   |
| <kbd>↓</kbd> / <kbd>↑</kbd> | Roving focus across items + checkbox items.            |
| <kbd>Home</kbd> / <kbd>End</kbd> | Jump to the first / last item.                    |
| <kbd>Enter</kbd> · <kbd>Space</kbd> | Activate the focused item.                     |
| <kbd>Esc</kbd>     | Close the menu and return focus to the trigger.                 |
