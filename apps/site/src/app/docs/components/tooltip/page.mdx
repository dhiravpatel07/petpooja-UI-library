# Tooltip

Anchored info panel that surfaces a description, an optional title row (with a leading icon and × close affordance), and an inline action cluster. Twelve placements cover every Pantheon position — `top/bottom/left/right` × `start/center/end`.

Pixel-perfect port of Figma node `2380:1293` (Pantheon › Tooltip). Built on **Radix Popover** (not Radix Tooltip) so the panel can hold interactive content — CTAs, the close button, links — with focus management, click-outside, ESC dismissal, and portaling for free.

## Installation

<InstallCommand name="tooltip" />

Or via npm:

```bash
pnpm add @petpooja/ui
```

## Usage

```tsx
import { SimpleTooltip, Button } from '@petpooja/ui';

export function Demo() {
  return (
    <SimpleTooltip
      title="Title"
      description="Supporting line text."
      side="top"
    >
      <Button>Open tooltip</Button>
    </SimpleTooltip>
  );
}
```

Tooltip is built on Radix Popover (click-to-open) so it can hold interactive content. For the native hover/focus pattern, wire `open` to your own pointer-enter / leave handlers.

## API

### `Tooltip`

Re-export of `Popover.Root`. Owns the controlled / uncontrolled open state via `open` / `defaultOpen` / `onOpenChange`. Use it as the wrapping component when you need full control over the slots.

### `TooltipTrigger`

Re-export of `Popover.Trigger`. Pass `asChild` to inherit the trigger element your call-site already renders (e.g. a `<Button>`).

### `TooltipContent`

The floating panel. Renders via a portal, takes `side` / `align` / `sideOffset` from Radix, and applies the Pantheon chrome (`Surface/Tertiary` `#F0F0F0`, 12 px radius, 16 px padding, 296 px max-width, subtle elevation).

### `TooltipHeader` · `TooltipTitle` · `TooltipIcon` · `TooltipClose`

The top row primitives. `TooltipHeader` spreads its children with `justify-between` so the close button hugs the right edge. `TooltipClose` is the Radix `Popover.Close` styled as a 16×16 button — clicking it dismisses the panel without extra wiring.

### `TooltipDescription`

The supporting paragraph — Inter Regular 14/22 #000 with an 8 px gap from the header above.

### `TooltipActions` · `TooltipAction`

`TooltipActions` is a right-aligned, gap-2 wrapper. `TooltipAction` is the text-button variant — pass `variant="primary"` for the confirm-style emphasis or `closeOnClick` to dismiss the panel as the click fires.

<PropsTable
  rows={[
    { name: 'variant', type: '"secondary" | "primary"', default: '"secondary"', description: '`secondary` is Inter Medium; `primary` bumps to SemiBold so the confirm action reads stronger.' },
    { name: 'closeOnClick', type: 'boolean', description: 'Render the button as the Radix close affordance — dismisses the tooltip when activated.' },
  ]}
/>

### `TooltipArrow`

12 × 6 px triangle in the same `#F0F0F0` fill. Radix auto-rotates it for every `side`. Place inside `<TooltipContent>` as the last child.

### `SimpleTooltip`

Prop-driven wrapper for the common "trigger + title + description + (optional) actions" pattern.
