# Table

Composable data-table primitives for dashboards, lists, and admin surfaces. One set of pieces — `Table`, `TableRoot`, `TableHeader`, `TableBody`, `TableRow`, `TableHead`, `TableCell` — plus higher-level helpers (`TableToolbar`, `TablePagination`, `TableStatus`, `TableLink`, `TableExpandToggle`) covers every variant on the Pantheon canvas: sortable headers, selectable rows, expandable rows with sub-rows, status pills, link cells, and numeric columns.

Pixel-perfect port of Figma node `2436:798` (Pantheon › Data Table). The outer container draws the 10&nbsp;px-radius border; row hairlines come from `Border/Primary` `#E5E5E5`; selected rows take the `Surface/Brand` `#E8F1FD` wash plus a 3&nbsp;px brand left rail; the selection toolbar swaps the chrome to the brand tint to make the active mode unmistakable.

## Installation

<InstallCommand name="table" />

Or via npm:

```bash
pnpm add @petpooja/ui
```

## Anatomy

```tsx
<Table>
  <TableToolbar>
    <TableToolbarInfo>3 items selected</TableToolbarInfo>
    <TableToolbarActions>
      <TableToolbarLink>Select all 200 items</TableToolbarLink>
      <TableToolbarLink>Clear All</TableToolbarLink>
    </TableToolbarActions>
  </TableToolbar>

  <TableRoot>
    <TableHeader>
      <TableRow>
        <TableHead sortable sortDirection="asc">Header</TableHead>
        <TableHead align="right">Numbers</TableHead>
      </TableRow>
    </TableHeader>
    <TableBody>
      <TableRow selected>
        <TableCell><TableLink href="#">Body</TableLink></TableCell>
        <TableCell numeric>4,325</TableCell>
      </TableRow>
    </TableBody>
  </TableRoot>

  <TablePagination
    page={1}
    pageSize={10}
    total={200}
    onPageChange={setPage}
    onPageSizeChange={setPageSize}
  />
</Table>
```

## Expandable rows

`TableExpandToggle` flips the chevron and toggles your own state. Render sub-rows underneath with `sub` for the `Surface/Secondary` wash and an indented label to match the Figma hierarchy.

## API

### `Table`

Outer wrapper — draws the 10&nbsp;px-radius border, sets the Inter font stack, and clips children with `overflow: hidden` so the corners read correctly. Forwards every `<div>` attribute.

### `TableRoot`

The actual `<table>` element. Sits between toolbar and pagination.

### `TableToolbar` · `TableToolbarInfo` · `TableToolbarActions` · `TableToolbarLink`

The horizontal bar that sits above the table when rows are selected. `TableToolbarInfo` holds the "N items selected" caption; `TableToolbarActions` is the right cluster (buttons or links); `TableToolbarLink` is the plain text-brand affordance used for "Select all 200 items" / "Clear All" / "Clear Selection".
