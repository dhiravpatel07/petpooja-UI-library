# Text

Polymorphic typography primitive that ports the full Pantheon ramp — twelve tiers (Display / Title / Body / Label, each in Large / Medium / Small) × four weights (Regular / Medium / SemiBold / Bold) — into a single component driven by `variant`, `size`, and `weight`.

Pixel-perfect port of Figma node `66:686` (Pantheon › Typography). Convenience aliases — `<Display>`, `<Title>`, `<Body>`, `<Label>` — lock the variant for cleaner call-sites; the underlying `<Text>` exposes everything else (semantic colour, alignment, truncation, multi-line clamp, italic / underline / strikethrough, and an `as` prop for the rendered element).

## Installation

<InstallCommand name="text" />

Or via npm:

```bash
pnpm add @petpooja/ui
```

## Usage

```tsx
import { Text, Display, Title, Body, Label } from '@petpooja/ui';

export function Demo() {
  return (
    <article>
      <Display size="md" as="h1">Welcome back</Display>
      <Title size="md" color="secondary">Western region · today</Title>
      <Body>Service ran without incident.</Body>
      <Label>Updated 2 min ago</Label>
    </article>
  );
}
```

Pass `weight` to override the default per tier — `regular` (400), `medium` (500), `semibold` (600), `bold` (700).

The `color` prop maps to the Pantheon `Text/*` palette so call-sites stay free of raw hex values. Override with `className` when you need a one-off.

## Truncation + clamp

`truncate` collapses to one line with an ellipsis. `numLines` clamps to N lines via `-webkit-line-clamp` — `numLines` wins when both are set.

<ComponentPreview
  previewClassName="!p-8"
  preview={<TextTruncateDemo />}
  code={`<Body truncate>…</Body>          {/* one line + ellipsis */}
<Body numLines={2}>…</Body>      {/* two-line clamp */}
<Body numLines={3}>…</Body>      {/* three-line clamp */}`}
/>

## Polymorphic `as`

Every component is polymorphic — pass `as` to swap the rendered element. Default tags are picked per variant + size so the document still reads as a sensible outline (Display → `<h1>`, Title large → `<h2>`, etc.).

<ComponentPreview
  previewClassName="!p-8"
  preview={<TextPolymorphicDemo />}
  code={`<Display size="md" as="h1">Daily kitchen report</Display>
<Title   size="md" as="h2" color="secondary">Western region · 16 May</Title>
<Body>
  Service ran without incident — SLA was met on
  {' '}<Text as="a" href="#" color="brand" underline>every dispatch lane</Text>.
</Body>
<Body color="secondary">
  Note: maintenance starts at <Text as="time" weight="semibold">02:00</Text> tomorrow.
</Body>`}
/>

### `Display` · `Title` · `Body` · `Label`

Thin wrappers around `<Text>` that lock `variant`. Every other prop is forwarded.

```tsx
<Display size="lg">Hero copy</Display>          // variant="display"
<Title size="md">Section header</Title>          // variant="title"
<Body>Paragraph copy.</Body>                     // variant="body" (default size md)
<Label color="secondary">Caption</Label>         // variant="label"
```

### `TYPOGRAPHY_TOKENS`

The raw ramp as a plain object — useful for design-token tables, Storybook stories, or generating CSS variables.

```ts
import { TYPOGRAPHY_TOKENS } from '@petpooja/ui';

TYPOGRAPHY_TOKENS.title.lg;
// → { fontSize: 20, lineHeight: 26, defaultWeight: 'regular' }
```
