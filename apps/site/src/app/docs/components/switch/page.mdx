# Switch

A two-state toggle. Sixteen documented variants in Figma — Large / Small × Default / Disabled × Off / On × with or without a check icon inside the thumb.

Built on **Radix Switch** so ARIA roles, focus management, keyboard activation (Space), and form integration come for free. Pixel-perfect port of Figma node `2382:278`.

## Installation

<InstallCommand name="switch" />

Or via npm:

```bash
pnpm add @petpooja/ui
```

## Usage

```tsx
import { Switch } from '@petpooja/ui';

export function Demo() {
  return <Switch defaultChecked />;
}
```
