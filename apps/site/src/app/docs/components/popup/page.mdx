# Popup

Centered modal for confirmations, alerts, and short content surfaces. Two documented variants from Figma: **Default** (icon + title + body + actions) and **Image** (media + title + description + actions).

Built on **Radix Dialog** so ARIA roles, focus trap, ESC dismissal, scroll lock, and click-outside come for free. Pixel-perfect port of Figma node `66:688`.

## Installation

<InstallCommand name="popup" />

Or via npm:

```bash
pnpm add @petpooja/ui
```

## Anatomy

```tsx
<Popup>
  <PopupTrigger />
  <PopupContent>
    {/* Default: */}
    <PopupHeader>
      <PopupTitle />
      <PopupCloseIcon />
    </PopupHeader>
    <PopupBody>
      <PopupDescription />
    </PopupBody>

    {/* …or Image variant: */}
    <PopupMedia>
      <img />
      <PopupCloseIcon className="absolute right-4 top-4" />
    </PopupMedia>
    <PopupBody>
      <PopupTitle />
      <PopupDescription />
    </PopupBody>

    <PopupFooter>
      <PopupClose>Secondary</PopupClose>
      <PopupClose>Primary</PopupClose>
    </PopupFooter>
  </PopupContent>
</Popup>
```
