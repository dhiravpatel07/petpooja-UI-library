# Card

Surface for grouping related content. Two layouts and an optional interactive mode.

- **Stacked** — full-width media on top, title block + actions below. Use for content lists where each card stands alone.
- **Horizontal** — square thumbnail on the left, title block + trailing slot on the right. Use for compact list rows.

When `interactive`, the card becomes a focusable, keyboard-activatable button with a `#fafafa` Pressed state. Pixel-perfect port of Figma node `2:113`.

```tsx
    <CardDescription />
    <CardFooter />

</Card>
```

## States

### Default vs Pressed

The Pressed state is just the active state — Figma documents it explicitly because it's part of the interactive feedback. The component triggers it via the `:active` pseudo-class when `interactive` is set; consumers can also force it for documentation by overriding the background.

## Interactive

When `interactive`, the card:

- Receives `role="button"` and `tabIndex={0}` so screen readers announce it correctly and keyboard users can focus it.
- Activates on **Enter** and **Space** in addition to mouse clicks.
- Triggers the Pressed background (`#fafafa`) via `:active` while a click is held.
- Gets a focus ring on `focus-visible` to satisfy keyboard accessibility.
