# Search

A single-line input with a magnifying-glass icon on the left and an auto-revealing clear (×) button on the right. The clear button appears as soon as the input has a value, and pressing it empties the input and returns focus there — the standard search-clear pattern.

Pixel-perfect port of Figma node `5376:906`. Composes well with any list-filtering UI.

## Installation

<InstallCommand name="search" />

Or via npm:

```bash
pnpm add @petpooja/ui
```

## Usage

```tsx
import { Search } from '@petpooja/ui';

export function Demo() {
  return <Search placeholder="Search menu" />;
}
```

## States

The clear button reveals automatically once the input has content. Disabled state dims the whole control and suppresses the clear button.

## Controlled (live filter)

Drive the value from React state with `value` + `onChange`. The clear button still works for controlled inputs — it dispatches a native `input` event so your `onChange` handler sees the cleared value.

<ComponentPreview
  previewClassName="!min-h-[420px] !p-8"
  preview={<SearchControlledDemo />}
  code={`'use client';
import { useState } from 'react';
import { Search } from '@petpooja/ui';

const ITEMS = ['Margherita pizza', 'Pepperoni pizza', 'Mushroom risotto', /* … */];

export function Demo() {
  const [query, setQuery] = useState('');
  const filtered = query
    ? ITEMS.filter((i) => i.toLowerCase().includes(query.toLowerCase()))
    : ITEMS;

  return (
    <div className="flex flex-col gap-4">
      <Search
        value={query}
        onChange={(e) => setQuery(e.target.value)}
        placeholder="Search menu items"
      />
      <ul>
        {filtered.map((item) => (
          <li key={item}>{item}</li>
        ))}
      </ul>
    </div>
  );
}`}
/>
