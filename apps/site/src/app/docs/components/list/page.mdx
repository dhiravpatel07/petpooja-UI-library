# List

Slot-based list row primitive that powers settings screens, navigation lists, selection menus, and feed cards. Six leading shapes (none / icon / image / checkbox / radio / switch) × five trailing shapes (none / icon / checkbox / radio / switch) × three text variants (Title only / Label + Title / Label + Title + Description) — every combination from the Pantheon spec is expressible.

Pixel-perfect port of Figma node `3461:3` (Pantheon › List). Each row is `Surface/Primary` with 16&nbsp;px horizontal and 8&nbsp;px vertical padding; the leading slot auto-aligns to the top when a description is present and a leading element exists, matching Figma's 3-line + image rule.


## Anatomy

```tsx
<List>
  <ListItem
    leading={<ListAvatar src="..." />}
    label="Label"
    title="Title"
    description="Supporting text"
    trailing={<Switch />}
  />
</List>
```

Or use the slots directly when you need full control:

```tsx
<ListItem>
  <ListItemLeading>{leading}</ListItemLeading>
  <ListItemContent>
    <ListItemLabel>Label</ListItemLabel>
    <ListItemTitle>Title</ListItemTitle>
    <ListItemDescription>Description</ListItemDescription>
  </ListItemContent>
  <ListItemTrailing>{trailing}</ListItemTrailing>
</ListItem>
```

## Text variants

Pass any combination of `label`, `title`, and `description`. Label sits above the title in Inter SemiBold 12/20 `#666`; Description sits below in Inter Regular 14/22 `#666` with a 4&nbsp;px gap. Title is the primary line in Inter Regular 16/24 `#000`.

## Three-line + image

When `description` is set and a leading slot is present, `alignLeading` auto-resolves to `"start"` so the avatar lines up with the top of the text block — exactly as documented in Figma's 3-line image variants.

## Interactive rows

Pass `interactive` to render the row inside a `<button>` with the Pantheon hover wash (`Surface/Secondary` `#FAFAFA`) and a keyboard focus ring. Combine with `onClick` for selection patterns.

### `ListItemLeading` · `ListItemContent` · `ListItemLabel` · `ListItemTitle` · `ListItemDescription` · `ListItemTrailing`

Lower-level slots. Use these when you need to render arbitrary content in the leading/trailing positions or override default truncation/typography.

### `ListAvatar`

56×56 image slot with the Pantheon `#F0F0F0` fallback bg, 8&nbsp;px corner radius, and `mix-blend-luminosity` overlay (matches Figma's monochrome placeholder look). Pass `preserveColor` to render the source image at full saturation.

<PropsTable
  rows={[
    { name: 'src', type: 'string', description: 'Image source URL.' },
    { name: 'alt', type: 'string', default: '""', description: 'Alt text for the image.' },
    { name: 'children', type: 'ReactNode', description: 'Override the rendered content (e.g. an inline SVG illustration).' },
    {
      name: 'preserveColor',
      type: 'boolean',
      description: 'Skip the luminosity blend mode. Use for full-color avatars.',
    },
  ]}
/>

### `ListIcon`

20×20 inline-flex container for trailing/leading icons. Inherits `text-black` so any SVG using `currentColor` picks up the correct fill.

### `ListDivider`

Standalone hairline (`#E5E5E5`) you can render between rows when `divided` is too uniform — e.g. to mark section breaks.
